# LJT-Homepage

Personal website of Junteng Liu, forked from [Academic Pages](https://github.com/academicpages/academicpages.github.io).

## Site content

- **About:** academic background, research experience, research interests and skills, publications, honors, and contact information.
- **Publications:** the same publication records as the About section, rendered from shared data.

Profile details are in `_config.yml`, `_data/authors.yml`, and `_pages/about.md`. Publication records are in `_data/publications.yml`. Only the About and Publications sections are in the navigation; there are no separate publication pages.

## Site configuration

Configured as a GitHub Pages project site at https://spadonidittrichmt848264.github.io/LJT-Homepage/. The existing Jekyll build and deployment workflow is retained, along with the upstream license.
